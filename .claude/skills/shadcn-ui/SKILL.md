# shadcn/ui Admin Skill

Use for the Admin CMS UI.

Stack: Next.js + TypeScript + shadcn/ui + Tailwind CSS.

## Responsibilities
- Admin layout
- Navigation/sidebar
- Tables and data grids
- Forms and validation UI
- Dialogs, sheets, dropdowns
- Status badges
- Filters/search
- Responsive admin UX
- Accessibility
- Loading, empty, error states

Reuse existing shadcn components before creating new ones. Do not introduce another component library without approval.
