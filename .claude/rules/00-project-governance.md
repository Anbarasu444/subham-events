# Project Governance Rules
- Treat `CLAUDE.md` as the constitution.
- Read `project/current-milestone.md` before significant work.
- Never work outside the active milestone without explicit approval.
- Do not interpret existing folders as permission to develop them.
- Record architectural decisions in `project/decisions.md`.
- Keep `project/progress.md` truthful and current.
- Do not declare a milestone complete without all gates passing.
