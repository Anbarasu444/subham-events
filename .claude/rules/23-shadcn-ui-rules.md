# shadcn/ui Rules

The Admin CMS uses Next.js with shadcn/ui.

- Use shadcn/ui as the primary reusable UI component system.
- Prefer accessible, composable components.
- Keep design tokens consistent.
- Do not add another UI component library without explicit approval.
- Keep business logic out of presentation components.
- Build reusable admin tables, forms, dialogs, sheets, filters, status badges, and command/search patterns.
- Preserve responsive behavior and keyboard accessibility.
- Do not blindly regenerate shadcn components; inspect existing components first.
